# abs

Веб-приложение домашних тренировок пресса и материалы к нему.

| Папка | Что там |
|---|---|
| [web/](web/) | приложение «Пресс»: React + TypeScript + Vite, PWA, работает офлайн, без аккаунта и оплаты. Подробности в [web/README.md](web/README.md) |
| [tz/](tz/) | техническое задание ([TZ.md](tz/TZ.md)), состав тренировок и список упражнений, исходные данные в JSON |
| `Abs Workout — веб-версия.html` | макет, с которого взят визуальный стиль |

## Быстрый старт

```bash
cd web
npm install
npm run dev
```
