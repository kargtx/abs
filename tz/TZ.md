## 0. Протокол чистой комнаты

| Роль | Кто | Что видит |
|---|---|---|
| Аналитик («грязная» сторона) | составитель ТЗ | референсное приложение, скрины, дампы разметки |
| Разработчики («чистая» сторона) | команда реализации | **только** этот документ и приложения A–C |

Правила:
1. Разработчики **не устанавливают и не открывают** референсное приложение, его APK, ресурсы и скрины из папки `screens/`. Скрины — материал аналитика; в разработку передаётся только текст ТЗ и нейтральные вайрфреймы, нарисованные заново.
2. Код референса не декомпилировался и не исследовался; все сведения получены наблюдением поведения через UI.
3. **Не переносятся:** название, логотип, бренд «P4P/Abs Workout», цветовая схема как фирменный стиль, тексты описаний, названия программ, видео/анимации упражнений, музыкальные треки, иконки, идентификаторы ресурсов.
4. **Переносятся (функциональные идеи и факты):** состав разделов, сценарии, типы данных, общепринятые названия упражнений, структура «упражнение — повторы/время — отдых».
5. Названия программ в продукте придумываются заново (в приложении B они даны только как ключи для сверки).
6. Все решения по UI принимает дизайнер чистой стороны на основе описаний раздела 4.

## 1. Описание продукта

Офлайн-ориентированное мобильное приложение (Android, далее iOS) для домашних тренировок мышц пресса и кора без оборудования. Пользователь выбирает готовую тренировку по уровню сложности или многонедельный план, выполняет её под управлением плеера (таймер/счётчик повторов, отдых, видео-демонстрация, музыка), отслеживает выполнение в календаре.

### 1.1 Целевая аудитория
Новички — продвинутые, мужчины и женщины, 18–45, тренировки дома 2–20 минут.

### 1.2 Наблюдаемые факты о референсе (для калибровки объёма)
- 3 уровня сложности: Новичок / Средний / Продвинутый; ~37 готовых тренировок (12 средних, 12 продвинутых, ~13 новичковых).
- Длительность тренировок 2–21 мин.
- Каталог: 41 упражнение в открытом каталоге; в тренировках среднего/продвинутого уровня используются 55 разных упражнений (16 из них в открытом каталоге не показаны).
- 8 многонедельных планов (4–8 недель, сессии 1–15 мин).
- 14 музыкальных подборок + «без музыки».
- 12+ языков интерфейса.
- Поддержка BLE-пульсометра.
- Облачный аккаунт (синхронизация своих тренировок и планов).
- Монетизация: встроенные покупки (раздел «Покупки» в настройках).

> ⚠ Исследованная сборка — **модифицированный APK** (в заголовке настроек «Release by Kirlif'», статус покупок «Неограниченный доступ»). Реальное поведение пейвола в референсе не наблюдалось; модель монетизации в разделе 4.10 проектируется самостоятельно.

## 2. Глоссарий

| Термин | Значение |
|---|---|
| Упражнение (Exercise) | Движение из каталога: название, сложность, тип, оборудование, описание, инструкция, ошибки, мышцы, видео |
| Шаг (Step) | Элемент тренировки: упражнение **или** отдых, с параметром «повторы» либо «длительность» |
| Отдых (Rest) | Шаг-пауза, всегда на время (в референсе 10–45 с, отображается иконкой паузы) |
| Тренировка (Workout) | Упорядоченный список шагов + метаданные (уровень, длительность, описание, музыка по умолчанию) |
| План (Plan) | Расписание тренировок на N недель с привязкой к дням недели |
| Сессия | Факт выполнения тренировки пользователем |

## 3. Информационная архитектура

Нижняя навигация, 5 вкладок (+ боковое меню с теми же пунктами и блоком профиля):

```
[Тренировки]  [Календарь]  [Планы]  [Упражнения]  [Настройки]
```

- Нижняя панель скрывается при прокрутке списка вниз и появляется при прокрутке вверх.
- Верхняя панель: кнопка меню (≡) / «назад», заголовок раздела, контекстное действие справа (например «+»).
- Боковое меню: шапка «Профиль» + статус («Вход» если не авторизован), пункты разделов.

Карта экранов:
```
Splash
└─ Main (tabs)
   ├─ Тренировки
   │   ├─ таб «Каталог» → Карточка тренировки → Плеер → Итог
   │   │                    ├─ Выбор музыки (модально)
   │   │                    ├─ Добавить в календарь
   │   │                    ├─ Настроить (редактор копии)
   │   │                    └─ Карточка упражнения
   │   └─ таб «Мои тренировки» → Конструктор («+»)
   ├─ Календарь
   ├─ Планы → Карточка плана → Начать план
   ├─ Упражнения → Карточка упражнения → Видео
   └─ Настройки → Язык / Пульс / Покупки / Поддержка / Политика / Условия
Авторизация (облако) — модальный экран
```

## 4. Функциональные требования

Приоритет: **M** — MVP, **S** — следующий релиз, **C** — по возможности.

### 4.1 Запуск и онбординг
- F-1.1 (M) Splash с логотипом не дольше 2 с, далее главный экран «Тренировки».
- F-1.2 (S) При первом запуске — выбор языка (по умолчанию — язык системы) и короткий онбординг (уровень подготовки → рекомендуемый уровень в каталоге).
- F-1.3 (M) Разрешения запрашиваются **только в момент необходимости** (уведомления — при создании расписания, Bluetooth — при подключении пульсометра). Референс запрашивает доступ к медиа при старте тренировки и к контактам/аккаунтам при открытии настроек — **так не делаем**: медиа хранится во внутреннем хранилище приложения, доступ к аккаунтам не нужен.

### 4.2 Каталог тренировок (вкладка «Тренировки»)
- F-2.1 (M) Два подтаба: «Каталог» (встроенные) и «Мои тренировки» (пользовательские).
- F-2.2 (M) Каталог сгруппирован по уровням сложности; заголовок группы — иконка уровня (3 полосы, заполнение и цвет по уровню: зелёный/оранжевый/красный), название, кнопка свернуть/развернуть.
- F-2.3 (M) Элемент списка: превью-картинка, название, иконка+подпись уровня (цвет уровня), бейдж-секундомер с длительностью в минутах.
- F-2.4 (M) Кнопка «наверх» (FAB со стрелкой) появляется после прокрутки.
- F-2.5 (C) Блок кросс-промо других приложений компании внизу списка (название + кнопка «Скачать» → стор).
- F-2.6 (M) «Мои тренировки», пустое состояние: текст «Пока нет созданных тренировок. Нажмите “+”…» + иллюстрация. Кнопка «+» в тулбаре открывает конструктор (4.4).
- F-2.7 (S) Отметка «выполнено» / счётчик прохождений на элементе списка.

### 4.3 Карточка тренировки
- F-3.1 (M) Шапка: превью, название, уровень, длительность (мин).
- F-3.2 (M) Описание (1–6 строк, собственные тексты).
- F-3.3 (M) Строка «Музыка: <подборка>» + действие «Изменить» → модальный выбор музыки (4.7).
- F-3.4 (M) Список шагов в порядке выполнения. Строка: миниатюра упражнения, название, справа значение — число повторов (`10`) или длительность (`0:30`, `1:00`). Шаг отдыха: иконка паузы вместо миниатюры, название «Восстановление/Отдых», длительность. Значения рендерятся моноширинным «табло»-шрифтом.
- F-3.5 (M) Тап по шагу-упражнению → карточка упражнения (4.6).
- F-3.6 (M) Нижняя панель: «Добавить в календарь», «Настроить», основная кнопка «НАЧАТЬ ТРЕНИРОВКУ» (на всю ширину, закреплена).
- F-3.7 (S) «Настроить» — создаёт копию тренировки в «Мои тренировки» и открывает её в конструкторе. В референсе требует облачного входа; у нас — **работает локально без аккаунта**.
- F-3.8 (M) «Добавить в календарь» — выбор даты/времени, повтор по дням недели, локальное напоминание. В референсе требует входа; у нас — локально.
- F-3.9 (M) Длительность в минутах вычисляется: Σ(время шагов на время) + Σ(повторы × темп упражнения, с) + Σ(отдых), округление вверх. Темп (секунд на повтор) хранится у упражнения (по умолчанию 2 с).

### 4.4 Конструктор своей тренировки (S)
- F-4.1 Название, уровень, описание, музыка.
- F-4.2 Добавление шага: выбор упражнения из каталога (с поиском и фильтрами) или «Отдых».
- F-4.3 Для шага: режим «повторы» (1–200) или «время» (5 с – 10 мин, шаг 5 с).
- F-4.4 Перестановка drag-and-drop, удаление свайпом, дублирование шага/блока, «повторить блок N раз».
- F-4.5 Предпросмотр вычисленной длительности.
- F-4.6 Сохранение локально; при входе в аккаунт — синхронизация (4.11).

### 4.5 Плеер тренировки (M)
> **Плеер в референсе недоступен для наблюдения.** При нажатии «Начать тренировку» показывается модальный диалог «Необходимо скачать несколько дополнительных файлов» со счётчиком файлов `0 / 16` (для 4‑минутной тренировки из 5 шагов) и кнопкой «Отмена»; без загрузки плеер не открывается. CDN контента референса больше не отвечает (запросы падают, превью тренировок/планов/музыки тоже не грузятся), поэтому загрузка не завершается никогда. Проверено и через VPN, с перезапуском приложения: соединение устанавливается, но сервер закрывает его без ответа («unexpected end of stream»), т. е. это не региональная блокировка, а отключённое хранилище. Вывод для нас: **плеер не должен блокироваться отсутствием медиа** — при недоступной сети тренировка запускается с текстовой карточкой/статичной иллюстрацией упражнения, а базовый набор миниатюр поставляется в сборке.
>
> Требования ниже проектируются самостоятельно по общепринятым для жанра решениям.

- F-5.1 Перед стартом: проверка наличия медиа упражнений. Если не загружены — диалог «Нужно скачать N МБ» (размер явно, не только число файлов), загрузка с прогрессом в байтах, возможность отмены; по Wi‑Fi — без вопроса (настройка). Ошибка сети → сообщение и кнопки «Повторить» / «Начать без видео» (не бесконечное ожидание).
- F-5.1a Медиа предзагружаются в фоне при открытии карточки тренировки и после добавления в календарь/старта плана.
- F-5.2 Обратный отсчёт 3-2-1 перед первым шагом (с голосом/звуком).
- F-5.3 Экран шага: зацикленное видео/анимация упражнения, название, крупно — таймер (для шагов на время) или целевое число повторов с кнопкой «Готово/Далее» (для шагов на повторы); прогресс тренировки (шаг k из n, полоса), превью следующего шага.
- F-5.4 Шаг «Отдых»: обратный таймер, «+10 с», «Пропустить», превью следующего упражнения.
- F-5.5 Управление: пауза/продолжить, назад/вперёд по шагам, выход с подтверждением.
- F-5.6 Звук: фоновая музыка выбранной подборки, голосовые подсказки (название упражнения, «осталось 3…2…1», «отдых»), сигналы; раздельная громкость музыки и голоса; приглушение (ducking) музыки во время подсказок.
- F-5.7 Экран не гаснет во время тренировки (wake lock); работа при свёрнутом приложении с уведомлением-плеером.
- F-5.8 При подключённом пульсометре — текущий пульс и зона на экране плеера (4.9).
- F-5.9 Итог: длительность фактическая, число выполненных упражнений, оценка калорий (MET-модель), средний/макс пульс; кнопки «Готово», «Добавить в календарь/повторить».
- F-5.10 Факт выполнения сохраняется как сессия и отображается в календаре.

### 4.6 Каталог упражнений (вкладка «Упражнения»)
- F-6.1 (M) Сетка карточек в 2 колонки: номер `# N`, превью, название.
- F-6.2 (S) Поиск, фильтры: уровень, тип, оборудование, группа мышц.
- F-6.3 (M) Карточка упражнения: номер, название, видео/анимация, атрибуты: **Сложность**, **Тип** (например «Сопротивление»), **Оборудование** («Нет», «Гантель»…); разделы **Описание**, **Инструкции** (нумерованные шаги), **Общие ошибки** (маркированный список), **Задействованные мышцы** (маркированный список); кнопка «ВИДЕО УЧЕБНИК» (полноэкранное видео со звуком).
- F-6.4 (M) Каталог MVP — не менее 55 упражнений, покрывающих все движения из приложения C (тексты и видео — собственные).

### 4.7 Музыка
- F-7.1 (M) Модальный экран «Музыка» с закрытием (×); табы «Все» / «Избранное».
- F-7.2 (M) Список: «Без музыки» + подборки по жанрам (в референсе 14: Dance ×4, Hip Hop ×3, House ×2, Latin, R&B, Dubstep, Electro‑Punk и др.). У каждой — кнопка предпрослушивания (play/stop 15–30 с) и отметка «в избранное».
- F-7.3 (M) Выбор сохраняется для конкретной тренировки; у тренировки есть музыка по умолчанию.
- F-7.4 (M) Музыка — **только лицензированная** (royalty-free/собственная), подборки скачиваются по запросу.
- F-7.5 (C) Воспроизведение своих треков/интеграция со Spotify и т. п.

### 4.8 Календарь
- F-8.1 (M) Месячная сетка (пн–вс, начало недели — понедельник; локализуемо), навигация ← месяц →, отметка «сегодня».
- F-8.2 (M) Дни с запланированными тренировками и выполненными сессиями отмечаются разными маркерами; тап по дню — список на день (запланировано/выполнено) с переходом к тренировке.
- F-8.3 (M) Кнопка «+» в тулбаре — запланировать тренировку на дату.
- F-8.4 (M) Локальные напоминания в запланированное время; переживают перезагрузку устройства.
- F-8.5 (S) Экспорт событий в системный календарь (по согласию).
- F-8.6 (M) Настройка «Удалить все расписания в календаре» (с подтверждением).

### 4.9 Пульсометр (S)
- F-9.1 Экран-интро «Пульс»: заголовок, пояснение пользы, «Подробнее», основная кнопка «Подключить».
- F-9.2 Поиск BLE-устройств со стандартным Heart Rate Service (0x180D, характеристика 0x2A37), список найденных, подключение, запоминание устройства, автопереподключение.
- F-9.3 Ввод возраста (для расчёта зон: 50–60–70–80–90 % от 220−возраст или по формуле Танаки).
- F-9.4 Отображение пульса в плеере и в итоге.

### 4.10 Покупки и доступ (M)
- F-10.1 Бесплатно: часть тренировок (например весь уровень «Новичок» + 2–3 средних), каталог упражнений целиком, 1 план.
- F-10.2 Премиум (подписка мес/год + пробный период, или разовая покупка): все тренировки, все планы, конструктор, все музыкальные подборки, пульсометр.
- F-10.3 Закрытые элементы — с иконкой замка; тап → пейвол.
- F-10.4 В настройках — блок «Покупки»: текущий статус, «Восстановить покупки», управление подпиской.
- F-10.5 Google Play Billing (актуальная версия) / StoreKit 2; проверка чеков на сервере.

### 4.11 Аккаунт и облако (S)
- F-11.1 Приложение **полностью работает без аккаунта**.
- F-11.2 Экран входа: заголовок, текст о пользе (синхронизация своих тренировок, планов, истории между устройствами), кнопка «Вход», «Выход/Позже». Способы: Google, Apple, e‑mail.
- F-11.3 Синхронизация: мои тренировки, расписание, история сессий, избранная музыка, прогресс планов. Конфликты — last-write-wins по полю `updatedAt`.
- F-11.4 Удаление аккаунта и данных из приложения (требование сторов).

### 4.12 Планы (вкладка «Планы»)
- F-12.1 (M) Список карточек-баннеров: обложка с названием, строка параметров «N недель | X – Y мин за сеанс».
- F-12.2 (M) Карточка плана: обложка, параметры, описание (свёрнуто до 5 строк + «Читать больше»), блок «Расписание»: подпись «Все программы начинаются в понедельник» и календарная сетка на весь срок плана, где дни тренировок выделены заливкой, отрезок плана — фоном, «сегодня» — обводкой; блоки преимуществ (3 пункта: заголовок + текст); закреплённая кнопка «НАЧАТЬ ПЛАН».
- F-12.3 (M) Старт плана: дата начала = ближайший понедельник (или выбрать вручную — S), создание расписания в календаре, напоминания.

## 5. Модель данных

```text
Exercise {
  id: string                 // стабильный, свой (не из референса)
  number: int                // порядковый номер в каталоге, «# N»
  name: LocalizedString
  difficulty: BEGINNER | INTERMEDIATE | ADVANCED
  type: RESISTANCE | CARDIO | STRETCH | ISOMETRIC
  equipment: [NONE | DUMBBELL | MAT | ...]
  muscles: [ABS | OBLIQUES | LOWER_BACK | HIP_FLEXORS | CHEST | TRICEPS | GLUTES | ...]
  description: LocalizedString
  instructions: [LocalizedString]
  commonMistakes: [LocalizedString]
  secondsPerRep: float       // для расчёта длительности, по умолчанию 2.0
  bilateral: bool            // «на каждую сторону»
  media: { thumb: url, loop: url, tutorial: url, sizeBytes: int }
  isPremium: bool
}

Step {
  kind: EXERCISE | REST
  exerciseId?: string
  mode: REPS | TIME
  value: int                 // повторы или секунды
}

Workout {
  id, name: LocalizedString, description: LocalizedString
  difficulty, coverImage
  steps: [Step]
  defaultMusicId?: string
  isPremium: bool
  source: BUILTIN | USER
  createdAt, updatedAt
  // durationMin — вычисляемое (F-3.9)
}

MusicPack { id, name, genre, previewUrl, tracks: [url], sizeBytes, isPremium }

Plan {
  id, name, description, cover, weeks: int
  benefits: [{title, text}]
  days: [{ weekIndex, weekday(1..7), workoutId }]
  isPremium
}

UserPlan { planId, startDate, status: ACTIVE|PAUSED|DONE|ABANDONED, completedDays: [date] }

Schedule { id, workoutId, dateTime, repeatRule?, reminder: bool, source: MANUAL|PLAN }

Session {
  id, workoutId, startedAt, finishedAt
  completedSteps: int, totalSteps: int
  kcal?: float, avgHr?: int, maxHr?: int
}

UserSettings { language, musicVolume, voiceVolume, voiceHints, countdown, wifiOnly,
               hrDeviceId?, age?, favoriteMusic: [id], workoutMusic: {workoutId: musicId} }
```

Контент (упражнения, тренировки, планы, музыка-метаданные) поставляется JSON-манифестом с версией: встроенный в сборку + обновление с сервера. Медиа — CDN, ленивое скачивание, кэш.

## 8. Критерии приёмки MVP

1. Каталог: ≥ 30 тренировок в 3 уровнях, длительность и состав совпадают с данными контента.
2. Пользователь без аккаунта может: выбрать тренировку → сменить музыку → пройти её в плеере от начала до итога → увидеть отметку в календаре.
3. Запланированная тренировка присылает напоминание в заданное время, в т. ч. после перезагрузки.
4. План стартует с ближайшего понедельника, расписание отображается в карточке и в календаре, прогресс сохраняется.
5. Карточка каждого упражнения содержит все поля F-6.3 и видео.
6. Премиум-контент закрыт до покупки; покупка и восстановление работают в тестовом режиме Play Billing.
7. Приложение не запрашивает разрешений сверх перечисленных в N-9.
8. Контент-аудит: ни один текст, название программы, изображение, видео, трек не совпадает с референсом.

## 9. Открытые вопросы

1. Модель монетизации: подписка или разовая покупка? Состав бесплатной части.
2. Производство видео упражнений: съёмка с тренером или 3D-анимация (влияет на бюджет и размер медиа).
3. Источник музыки (стоки/заказ) и лицензия на офлайн-воспроизведение.
4. Нужен ли собственный бэкенд в MVP или достаточно Firebase (Auth + Firestore + Storage).
5. Поведение плеера (раздел 4.5) — подтвердить на прототипе; в референсе плеер не открывается (CDN контента не работает), верифицировать нечем. Если нужна сверка — найти пользовательские видеообзоры или более новую официальную версию.
