# Пресс: веб-приложение тренировок пресса

PWA на React 18 + TypeScript + Vite + zustand. Данные хранятся в `localStorage`, бэкенда, аккаунтов и оплаты нет.
Визуальный стиль взят из макета `../Abs Workout — веб-версия.html`.

## Запуск

```powershell
cd web
npm install
npm run dev      # http://localhost:5173
npm test         # контент, названия из tz/APPENDIX_C, длительность, даты
npm run build    # сборка в dist/ (с офлайн-кэшем через service worker)
```

## Что внутри

| Раздел | Что есть |
|---|---|
| Главная | прогресс (тренировки, минуты, дни подряд), активный план, три уровня-серии с прогрессом, последние тренировки |
| Уровень | нумерованный список тренировок, отметки «выполнено» и «далее» |
| Тренировка | длительность, упражнения, отдых, музыка, «Настроить» (копия в «Мои»), «Начать» |
| Плеер | подготовка, анимированная фигурка в темпе упражнения, **счёт повторов вслух**, кольцо-таймер, «Смените сторону» или «Половина» на середине, отдых с «+10 с» и «Пропустить», пауза и переходы, wake lock, итог |
| Упражнения | 57 упражнений: **английские названия** (русское исходное — подписью в карточке), исходные номера `# N`, поиск на обоих языках, фильтр по мышцам |
| Планы | 7 планов, старт с ближайшего понедельника, сетка расписания, прогресс |
| Мои | конструктор: повторы или время, отдых, порядок, дублирование |
| Настройки | голос и счёт (вкл/выкл, темп, голос, скорость, высота, громкость), подготовка, отдых, музыка, вес, язык RU/EN, сброс данных |

## Счёт повторов
- Шаг на повторы ведётся счётом «Раз, Два, Три…» в темпе упражнения (`secondsPerRep` × «Темп счёта») и сам переходит дальше. Кнопка «Готово» завершает шаг раньше.
- В шагах на время повторы тоже считаются вслух, кроме статики (планки).
- Если счёт выключен, шаг на повторы ждёт нажатия «Готово».

## Ограничения
- Тексты описаний упражнений собственные. Названия упражнений показываются и озвучиваются по-английски.
- Набор голосов зависит от браузера: больше всего русских голосов обычно в Chrome и Edge.

## Сервер

Выкладка под pm2 (процесс `press`, `pm2 serve` в режиме SPA): создайте `web/.deploy.env` со строками `HOST=user@server` и `PORT=4444`, затем `bash deploy.sh`. Нужен вход на сервер по SSH-ключу.
